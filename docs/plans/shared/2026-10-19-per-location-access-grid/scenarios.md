# Scenarios: Per-location access grid

**Plan:** docs/plans/shared/2026-10-19-per-location-access-grid/plan.md
**Coverage:** 66 scenarios — 23 happy · 10 edge · 8 failure · 24 security · 1 guard

Each scenario is one test (a test with several data rows counts once). Every new test except the guard (16, which passes now because the audit interceptor already refuses another organization's rows) fails now for the right reason: a stub that throws `NotImplementedException`, a failed assertion, or a model or table that does not exist yet. The count is above the budget for a plan of this size (L: 40) because the plan has 10 tasks in 4 modules and the security skill requires a refusal test per disallowed case; Gate 2 can cut scenarios the reviewer finds redundant.
