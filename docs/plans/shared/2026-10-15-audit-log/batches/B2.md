## T2 — Read audit log endpoint
| Field | Value |
|---|---|
| Expected context | T1's audit DbContext applies the tenant query filter, so reads see only the token organization. Permission policies exist (`AddPermissionPolicies`, `PermissionAuthorizationHandler`): a policy named `reports.view` passes only when the token has an organization and one of its roles grants it (Owner, Admin, Manager today). No endpoint uses a permission policy yet; this one does, at the controller. Controllers stay HTTP-only and return DTOs; the service maps with a private static `MapToResponse`. The host registers each controller assembly with `AddApplicationPart` |
| Expected result | `GET /api/audit-log` returns the token organization's entries, newest first, filtered by optional `from` / `to` (UTC, inclusive) and optional `action`. Results are paged (page and page size, page size capped at 100, default 50). `from` later than `to`, or an unknown action, returns 400 with a localized message. No update or delete endpoint exists |
| Outcome | #2: with entries in Org A and Org B, an Org A user reads only Org A's. #3: a user without reports.view gets 403 |
| Files | `add` controller under `src/RestaurantManagement.Shared/Controllers/` · `add` read service and its interface under `src/RestaurantManagement.Shared/Services/AuditLog/` · `add` query and response DTOs under `src/RestaurantManagement.Shared/Models/` · `change` `src/RestaurantManagement.Shared/Localization/SharedResource.resx` and `.pt.resx` (new messages) · `change` `src/RestaurantManagement.Web/Program.cs` (register Shared controllers and read service) · `add` endpoint tests in `tests/RestaurantManagement.Web.Tests/` |
| Modules | Shared, Web (host registration only) |
| Flags | New endpoint behind the reports.view permission policy |
| DoD | Tests written and passing (Web.Tests via `TenantApiFactory`) · cross-tenant: Org B's entries never appear for an Org A token, including when Org B's ID is passed in the query · 403 for Cashier, Waiter and Kitchen (one test each) · 403 for a token with no organization selected · 401 without a token · Owner, Admin and Manager get 200 · date filter and action filter each narrow results · newest first and page size cap · 400 for `from` after `to` and for an unknown action · message catalog completeness test still green · build green |
| Depends on | T1 |
| Uses from dependency | Audit DbContext and entity, action constants, test factory migration |
| Provides | Read endpoint used by T3 and T4 end-to-end tests |
