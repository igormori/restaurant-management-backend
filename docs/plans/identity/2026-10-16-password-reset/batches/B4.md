## T5 — Password audit recorder
| Field | Value |
|---|---|
| Expected context | `IAuditLog.RecordAsync` (Shared) stamps organization from `ITenantScope` or the token; it refuses an entry without an organization. Reset is anonymous and change may run before an organization is selected. `AuditActions` lists allowed actions. Identity owns `UserRoles`, which hold each organization the user belongs to. Decided by the user: one entry per organization the user holds a role in, none when the user has no organization |
| Expected result | An Identity helper records one audit entry per distinct organization in the user's roles, each inside `ITenantScope.Begin(organizationId)`. Entry: action `password.reset` or `password.changed` (new `AuditActions` constants), entity type user, entity ID the user's ID, no Before, After or Reason values. A user with no organization gets no entry |
